# Workflow v1

The coordinator sequences work using the `DEPENDENCIES` handoffs in the
brief. Name the producer, consumer, and required result or contract. Dispatch
independent work in parallel when its ownership and checkout are verified.
Wait for the named handoff before sending work that depends on it, and update
the affected briefs if the handoff changes.

Set `WORKFLOW: v1` in Felix and Vera briefs. Identify the actual diff or
worktree as `REF`. Before landing each parallel stream, run the checker with
its base commit, actual worktree, and declared `WRITE OWNERSHIP` patterns.

```bash
skills/verification/scripts/check-ownership.sh \
  --base "$base" --worktree "$worktree" -- "${write_ownership[@]}"
```

Require `OWNERSHIP PASS` and Vera's independent `PASS` on that diff and its
acceptance evidence. If the diff changes before landing, rerun the checker
and have Vera review the changed diff. After landing the streams, run the
separate combined check. Route defects to the owning Felix or give one
integration Felix explicit ownership of the affected paths. The shared
two-round recovery cap applies to both kinds of fix.
