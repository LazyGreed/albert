# Architecture and operator playbook

Use this as a dispatch registry, not a taxonomy that implies exhaustive coverage of future models. Each row is a starting diagnostic and edit candidate, not a validated recipe. Select only relevant rows, compose them for hybrids, and verify against actual source equations. Every intervention requires matched controls and every edit requires the parent skill's independent regression gates.

## Architecture adapters

| Architecture / family | Inspect and localize | Causal test and candidate repair | Mandatory extra regression |
|---|---|---|---|
| Linear/logistic, GLM, shallow classifiers | feature scaling, coefficients, intercepts, margins, calibration | isolate features/counterfactuals; analytically repair intercept or constrained coefficients | calibration, boundary cases, correlated features |
| MLP, ReLU, residual MLP, gated MLP (SwiGLU/GeGLU), MLP-Mixer | activation rates, thresholds, signed GLU output vectors ($+w$/$-w$ gated on $g\cdot x>0$ to ignore SiLU negative leak), channel/token mixing, residual branches | exact piecewise analysis for small ReLU; signed activation ablation (screen opposite sign for Type-2 concepts), bias/channel/low-rank edits for larger nets | active-region coverage, opposite-sign (Type-2) preservation, residual scaling, nonlinear effects |
| CNN, ResNet, depthwise/separable, dilated or deformable conv | filter responses, receptive fields, stride/padding, feature maps, offset predictors | patch feature maps at matched spatial locations; constrained filter/channel or normalization repair | translations, scales, boundaries, aliasing, grouped weight layout |
| U-Net, encoder-decoder, FPN, segmentation/detection | skips, resolution/upsampling, proposal/head scores, NMS | patch encoder/skip/decoder separately; repair localized feature or head | small objects, boundaries, class imbalance, coordinate transforms |

| Spiking/event-driven, reservoir, cellular automata | membrane/threshold/reset, spike timing, recurrence, reservoir/readout | controlled event/impulse input; perturb state/readout or threshold | temporal precision, event sparsity, reset, stability, hardware parity |

| KAN, splines, RBF, basis expansion, neural additive models | knots, basis coefficients, support, extrapolation and interaction structure | isolate input intervals/basis responses; bounded coefficient edits | continuity, extrapolation, monotonicity and knot boundaries |

| Ensembles, cascades, neural-symbolic, differentiable programs, modular systems | interfaces, calibration, aggregation, routing, symbolic constraints | replace modules with oracle stubs, isolate boundary error, edit correct component | interface invariants, end-to-end interactions, fallback behavior |

## Universal operator-level adapter template

For any unseen operator, define: `operator_id`, equation and dimensions, data/weight/state inputs, expected invariants, static checks, dynamic summaries, clean/corrupt pairs, safe causal intervention and controls, candidate constrained edit, neighboring dependencies, local metrics, whole-model regression and unsupported assumptions. If nonlinear or stateful, test representative regimes rather than assuming superposition. If stochastic, use paired seeds plus independent seed replication. If formal constraints cannot be enforced on a candidate edit, prefer a different intervention.

## Task overlays (use in addition to the backbone adapter)

- **Language and coding models:** separate next-token loss, exact recall, reasoning/algorithmic correctness, instruction following, tool schemas, syntax/compilation and unit/integration tests. Split code by repository/problem family, vary identifiers/languages and contexts. Test paraphrases, negative examples, multi-hop effects, unrelated capabilities, prompt formats and stop/decoding settings. Test the actual OpenAI/Anthropic-compatible serving wrapper separately from model weights: tokenization, roles/templates, streaming, tool-call parsing, and context truncation. Do not conflate API compatibility with coding competence.
  - *Unlearning & hidden-behavior audit overlay (SwiGLU LLMs):* When auditing finetuned/LoRA checkpoints or verifying knowledge removal, never rely on MCQ scores or surface refusals alone. Run (1) **cloze-scoring recovery probes** on facts the base model knew, (2) **top-changed-neuron activation spike checks** on forget vs. retain text (selective spikes on forget text with intact cloze ranks indicate backdoor-like suppression rather than deletion), and (3) **base-vs-finetune per-neuron vote diffs** + readout-aligned steering whenever per-matrix MLP drift is modest (< ~3%).
- **OCR/document and financial extraction:** use CER/WER, exact fields, geometry and reading order, layout F1, table cell structure and per-script error. Isolate Khmer/English, combining marks, digits, currency, stamps, fonts, rotations, low-quality scans and document-level leakage. Do not use post-correction improvements to conceal degraded raw recognition or financial field accuracy.
- **Speech/TTS:** test speaker-independent splits, phoneme and pronunciation coverage, duration alignment, intelligibility, naturalness with blinded listeners and matched sample count. Distinguish frontend, acoustic, vocoder and codec failures.
- **Vision:** object/segmentation/recognition metrics, transformations, image quality, class/domain slices, calibration and localization. Use image-level independent units rather than correlated pixels.
- **Generative media:** seed-paired quality/condition metrics plus independent seeds and human evaluation as needed; evaluate diversity, fidelity and regression of unrelated conditions; avoid claiming concept removal from a narrow prompt list.
- **Safety/decision/regression:** specify costs and asymmetric failure rates, representative sampling and critical subgroups, thresholds and tolerances. Use domain-approved tests and formal properties where feasible; no model-only clinical or regulatory clearance.

## Example: controlled recurrent-memory audit

Use a synthetic key/value or code-symbol retrieval task with clean and corrupted paired sequences. Vary gap, distractors, overwrite frequency, and target positions. Measure exact target retrieval/logit margin at the read position; keep unrelated next-token quality as preservation metric. Compare memory-free equal-byte state, random/recency policy, and oracle addressing; match data, steps and compute. Patch a stored value at write time, a matching state/slot before read time, and the copy/read output separately. If oracle addressing fixes retrieval, the address path is a candidate bottleneck, not proven sole cause. If oracle value and address both fail, inspect readout/use. Evaluate gradient path across the intended gap and distinguish training truncation from representational capacity. Use held-out gaps and seeds before recommending an edit or objective change.
